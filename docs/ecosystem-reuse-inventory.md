이 표는 #792와 이미 등록된 child issue를 한 행씩 연결한다. `source_anchor`와
`test_anchor`는 workshop caller를, `bluetape_source_anchor`와
`bluetape_test_anchor`는 이미 소비 중인 capability의 비교 기준을 가리킨다.
`actual_import`는 실제 Bluetape import를 포함한 source/test 파일 anchor이고,
`capability_api`는 해당 파일에서 사용하는 FQCN/API를 설명한다. dependency
declaration만 존재하거나 아직 import가 없는 후보는 `actual_import=N/A`와
`capability_api=candidate:` marker로 기록한다. released capability는
`bluetape_*_anchor`를 adoption 비교 기준으로 제공하며, fallback 분류는 이를
`N/A`로 둘 수 있다.
`status=pending`은 이 train에서 아직 변경·검증되지 않았다는 뜻이며,
`status=verified`는 해당 child의 fresh receipt와 대응 node `READY/PASS`가
확인되었다는 뜻이다. checker는 경로·분류·BOM alias·실행 계약을 먼저 검증한다.
