## 검토 범위

- #793 usage metering event-sourcing의 일반 식별자·JSON 경계를
  `Uuid.V7`와 `Jackson.defaultJsonMapper` 기준으로 정렬했다.
- #796 Operations Console의 일반 JSON mapper와 Ktor/Spring strict request
  parser를 Bluetape baseline 위에서 공유하도록 정렬했다.
- #798 shared HTTP helper 중복을 제거하고 upstream production/test API를
  소비하도록 전환했다. WebClient production provider gap에서는 native
  `WebClient` 호출을 사용하고, test helper는 `io.bluetape4k.spring.tests`를
  직접 사용한다.
- consumer module은 기존 `bluetape4k-dependencies` BOM 경계를 유지했으며,
  `docs/ecosystem-reuse-train.json`과
  `docs/ecosystem-reuse-inventory.md`는 변경하지 않았다.
