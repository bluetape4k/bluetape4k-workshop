# Workshop Ecosystem Code Patterns 매트릭스

날짜: 2026-07-04
조정 브랜치: `feat/workshop-ecosystem-code-patterns`

이 매트릭스는 등록된 모든 Gradle project를 추적한다. 각 row는 처리 상태가 `patched`, `no-op`, 또는 `follow-up`이고 P0/P1=0 리뷰 근거가 있을 때만
종료 상태로 간주한다.

표의 module name, PR number, head SHA, branch, command, workflow name, PASS/SUCCESS/P0/P1 같은 검증 식별자는 원문을 유지한다. 그 외 설명은
한국어로 재작성해 각 module이 어떤 생태계 pattern을 보존했는지, 안정성/보안 경계가 어떻게 판정되었는지, 어떤 로컬 및 GitHub 검증 근거로
종료 판단했는지 바로 확인할 수 있게 했다. README locale pair와 review artifact path는 추적 대상 evidence이므로 파일명을 보존한다.
이 문서는 이후 batch 리뷰의 기준표이기도 하므로 표의 구조는 바꾸지 않았다. 각 row는 후보 패턴, 처리 상태, 재사용 근거, 안정성/보안 판정,
검증 근거를 같은 순서로 유지해 stacked PR 검토자가 이전 batch와 이후 batch의 판단을 쉽게 대조할 수 있게 한다. 문장 안의 영어 식별자는
명령이나 공개 API를 가리킬 때만 남겼고, 상태 설명과 판단 사유는 한국어 문장으로 읽히도록 정리했다.
따라서 이 파일의 목적은 원문 번역을 넘어, 각 예제 모듈이 왜 완료 상태인지 한국어 독자가 빠르게 확인할 수 있는 검토 장부와 추적 기준, 감사 기준과 문서 품질 기준을 제공하는 것이다.
