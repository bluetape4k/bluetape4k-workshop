## 핵심 구현 확인

- 요청 thread가 `LeaderLockHandle`을 보관하거나 복사하지 않고 owner executor에서
  실제 `LockExtender.extendActiveLockDetailed`를 호출한다.
- global `LeaderLeaseExtensionObservers.addObserver`만 사용하며
  `LeaderLeaseExtensionObservationScope`/`addScopedObserver`를 consumer에 선제적으로
  참조하지 않는다.
- `ObservationRegistry.NOOP`와 `bluetape4k.leader.observation.enabled=false`에서는
  registration이 생기지 않는다.
- user extension은 `source=user`, watchdog은 `source=watchdog`으로 구분되고,
  cancellation/`Error`는 terminal event를 만들지 않는다.
