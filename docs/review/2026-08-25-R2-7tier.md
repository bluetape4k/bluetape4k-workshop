## 검토 범위

- #794 pre-generated voucher pool의 persistent allocation, reservation, entry,
  revocation grant ID를 `Uuid.V7.nextId()`로 정렬했다.
- #794 worker instance namespace는 `Base58.randomString(16)`으로 생성하고,
  SecureRandom revocation nonce와 서명 material은 cryptographic 계약을
  보존했다.
- #795 concert-ticket flash-sale 테스트 fixture의 UUID typed identity는
  `Uuid.V7.nextId()`로, run ID·Redis namespace·temporary artifact suffix는
  `Base58.randomString(...)`으로 정렬했다.
- #795 `grantNonce` 3곳은 승인 토큰의 보안 nonce이므로 raw UUID fallback을
  유지하고 각 사용 지점에 사유를 기록했다. DB·Redis·Docker·file cleanup,
  atomic publish, deterministic digest 계약은 변경하지 않았다.
- consumer BOM 경계를 유지했으며 `docs/ecosystem-reuse-train.json`과
  `docs/ecosystem-reuse-inventory.md`는 변경하지 않았다.
