## Artifacts and transformation

- [Raw JMH JSON](2026-07-27-all-profiles.json) contains every score, error,
  parameter, and secondary metric emitted by the run.
- [Derived summary](2026-07-27-summary.json) groups rows by benchmark method.
  Parameterized read benchmarks use the arithmetic mean across
  `productId=1,100,500`; non-parameterized methods retain their single score.
- README tables and charts round those summary scores to three decimal places.

## Interpretation limits

- Results come from one local host with containerized Redis and H2; they are
  not production throughput or sizing claims.
- Write-behind enqueue measures cache acceptance while persistence remains
  queued. It is not comparable to completed database writes.
- Write-behind drain includes the configured one-second delay and waits until
  the database exposes the queued update.
- Error bounds and individual parameter scores must be read from the raw JSON
  when comparing close results.
